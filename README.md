# Gamesquare

A GameCube-style startup and menu, in the browser. Play it at https://rhysflores.github.io/gamesquare/

Click to start. Arrow keys or WASD turn the menu cube; Enter opens a side; Tab goes back.

Games run in [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) (GPL-3.0, bundled in `emulatorjs/` with its license). Uploaded games and saves stay in your own browser.

There are a lot of secrets.
